# Atesta — product demo: narration and scene plan

Target length: 60–90 seconds. Generated from `tests/recording/narration.ts`, which also
drives the recording, the voice track and the captions, so all four always match.

The sample claimant and organisation are fictional; the public credential and NEAR testnet
transaction shown are real. The voice is synthetic, generated locally with Windows speech.

Lines marked **[NEAR]** are recorded only once the contract is on NEAR testnet and a real
token has been minted; until then they are left out of the video and its captions.

## Who Atesta is for

### Scene 1: open

**On screen:** The live Atesta public credential page for a contribution approved by Northstar Protocol.

> Open-source contributors and grant-funded developers need to show which team accepted their code.
>
> Atesta gives project maintainers and grant programmes a way to issue a credential for a specific GitHub contribution.
>
> This demo uses fictional people and an organisation, but its public NEAR testnet token is real.

## Check the record

### Scene 2: checks

**On screen:** The live integrity checks on the credential's public verification page.

> The first check confirms the public record matches its digest.
>
> The second reads the live NEAR testnet contract. It holds the same digest.

## Inspect the NEAR record

### Scene 3: chain

**On screen:** The active, non-transferable token details and the link to its real NEAR testnet mint transaction.

> The credential is active and non-transferable. The page names the issuer and holder and links to the real mint transaction.
>
> NEAR anchors this record publicly, so anyone can check it later.

## Close

### Scene 4: close

**On screen:** The matching digest checks and public transaction link on the live credential page.

> This can help open-source maintainers, grant reviewers and developer portfolio builders check a specific endorsement.
>
> In real use, the authorised organisation makes the decision. This sample shows how anyone can check the record. Try the live demo and inspect the repository.
